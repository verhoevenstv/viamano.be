# public/

Zet hier alle afbeeldingen en bestanden die rechtstreeks bereikbaar moeten
zijn op de website (foto's, logo, documenten).

Voorbeeld: leg je een bestand `public/karen.jpg`, dan gebruik je het op de
site via het pad `/karen.jpg`.

## Nog toe te voegen (placeholders in de code)

- Portretfoto van Karen (gebruikt op de homepage en op "Over mij")
- Eventueel sfeerbeelden (natuur, licht, rust)
- Een logo, als daar een ontwerp voor komt

> De favicon (het icoontje in het browsertabblad) staat als
> `src/app/icon.svg` en mag je later vervangen door een definitief ontwerp.
