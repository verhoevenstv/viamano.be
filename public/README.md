# public/

Zet hier alle afbeeldingen en bestanden die rechtstreeks bereikbaar moeten
zijn op de website (foto's, logo, documenten).

Voorbeeld: leg je een bestand `public/karen.jpg`, dan gebruik je het op de
site via het pad `/karen.jpg`.

## Logo

De logo-bestanden staan klaar:

- `logo-mark-navy.png` — handafdruk in navy, transparante achtergrond (in de header)
- `logo-mark-cream.png` — handafdruk in crème, transparante achtergrond (in de footer)
- `logos/logo-primary.png` — volledig hoofdlogo (handafdruk + AMANO + baseline)
- `logos/logo-primary-transparent.png` — hoofdlogo met transparante achtergrond
- `logos/logo-badge.png` — rond embleem
- `logos/logo-reversed.png` — lichte versie op donkere (slate) achtergrond
- `logos/logo-horizontal.png` — horizontale lockup
